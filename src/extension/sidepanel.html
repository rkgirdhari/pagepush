    Ollama is optional. The offline draft needs nothing installed.

    Ollama says 403 or will not connect?
    1. Install Ollama from ollama.com and make sure it is running (tray icon).
    2. Allow this extension once. In PowerShell: setx OLLAMA_ORIGINS "chrome-extension://*"
    3. Quit Ollama from the tray and start it again so it reads the new setting.
    4. Click Check / Load Model. The first load downloads the model (several GB) and can be cancelled.
