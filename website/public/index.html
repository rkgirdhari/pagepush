From client details to the final click, each step gives you a chance to see what comes next.

    Plan the open view

    ↗
  2. 02

    Draft into Facebook

    Draft writes supported values into Facebook’s form. Facebook may process those values before final approval.

    ↗
  3. 03

    Review on the page

    ↗
  4. 04

    Approve the final action

    Approve & Commit attempts the applicable Save, Post, or Create action. Confirm the outcome on Facebook; an attempt is not proof of success.

A LITTLE ROOM TO REWIND↺

Save up to 20 local snapshots of a client pack. Restoring first saves the current pack unless it matches the newest snapshot, resets the active plan and checklist, and asks you to plan again. It does not change Facebook.

GETTING SET UP 03 / 04

Try it locally.
Keep it yours.

Page Push is not yet available from the Chrome Web Store. If you have the project working copy, you can build and load the extension unpacked in Chrome 120 or newer.

Before you begin
You’ll need Node.js 22 or later, npm, and the Page Push project files. Use a test Business Page for the pending live dry run.
UNPACKED INSTALL↗
  1. 01
    Build the extension

    In the project folder, run npm install, then npm run build.

  2. 02
    Open Chrome extensions

    Go to chrome://extensions and turn on Developer mode.

  3. 03
    Load the build

    Choose Load unpacked, then select the project’s dist/ folder.

  4. 04
    Open your Business Page

    Open Page Push from Chrome and review the plan and draft before approval.

No account, checkout, or store link is offered on this site.

A NOTE ON YOUR DATA

Local by design.
Clear about the limits.

Pack data, saved versions, plans, and receipts live in the browser’s local extension storage. Drafting writes to Facebook; optional Ollama requests go to your local server.

Before clearing data, close other Page Push panels and wait for their work to finish. Another panel can restore stale data after a clear, so multi-panel erasure is not guaranteed.

GOOD TO KNOW 04 / 04

Questions,
answered.

Is Page Push ready for public release?+

Not yet. The extension has automated fixture coverage, but a real Chrome and Facebook end-to-end test, a live Ollama check, screenshots, publisher disclosures, and a public privacy URL remain open. The multi-panel erase limitation must also be resolved or explicitly accepted before release.

Does it post automatically?+

No scheduled or background posting. Draft enters values into Facebook before approval; the final action is attempted only after you review and approve. Verify the result on Facebook.

Can it upload profile or cover photos?+

No. Upload those on Facebook yourself. The checklist can help you remember the manual steps.

What happens to data when I clear it?+

Clear All removes extension-local packs, versions, plans, archives and settings when it succeeds. Other open panels can restore stale data; close them and wait for their work to finish first. Downloaded files, Ollama models, and Facebook data are separate.

Does the extension support other platforms?+

The extension is for Facebook Business Page setup. The repository also contains Devpost and AppSumo libraries, but they are not wired into the shipped browser extension.
